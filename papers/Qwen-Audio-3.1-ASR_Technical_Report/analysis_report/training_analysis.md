# Qwen-Audio-3.1-ASR：面向训练工作的专题分析

- **论文与版本**：[Qwen-Audio-3.1-ASR Technical Report，2610.28711v1](https://arxiv.org/abs/2610.28711v1)。
- **依据**：[main.tex](../src/main.tex) 的 §2–5；本报告区分原文披露、作者观察与个人建议，不构成已复现实验。
- **用户关注**：“要特别总结和训练相关的内容，这是我真正关心的，因为和我的工作相关”。

## 1. 训练路线与参数更新范围

全文最有用的线索是：先训练声学表征，再对齐到语言空间，再改变任务分布，随后进行任务化 SFT、指标驱动的 RL 和多教师在线蒸馏。它们并非在同一数据上重复训练。

| 阶段 | 数据与目标 | 明确披露的参数更新 | 主要作用与边界 |
|---|---|---|---|
| 1a. 编码器 BEST-RQ | 大规模无标注语音；随机掩码后预测固定随机投影与冻结码本产生的离散标签 | 训练编码器；兼容的 Transformer 层从 Qwen3 初始化，非流式编码器改用双向注意力；声学前端单独初始化 | 学习上下文声学表征；并非以 ASR 文本作为唯一监督 |
| 1b. 编码器 AED | 大规模带标签音频—文本，主要为中英文；自回归预测转写 | 编码器参与 AED 训练；之后丢弃 AED 解码器 | 加强声学—文本对应；1a、1b 合计仅披露“数千万小时”，没有分项时长 |
| 2. Audio LLM 预训练 | 约 2000 万小时多语种数据，以 ASR 和交错文本—音频为主；目标文本 CE | 冻结编码器，联合训练 adapter 与 MoE LLM | 大规模音频—语言对齐；没有公开各类样本配比 |
| 3. Cooldown | 约 100 万小时高质量数据；语言/方言再平衡，并加入音频理解、说话人、语音问答/对话 | 编码器继续冻结，训练 adapter 与 LLM，目标 token CE | 调整分布与任务覆盖；不能将其理解为仅仅调低学习率 |
| 4. SFT | ASR、结构化说话人转写、Next 的音频理解，按型号配置任务混合 | 更新编码器与 adapter；冻结 LLM 基座，仅训练解码器 LoRA | 显式学习指令、输出格式与非词汇声学任务 |
| 5. RL | 精选困难 ASR、多说话人音频及普通 ASR 回放；GRPO | 原文没有逐模块说明冻结范围 | 以识别、说话人和时间指标优化序列输出 |
| 6. 多教师 OPD | ASR、SD、AU，以及文本和对话；按任务分配教师 | 教师冻结；学生具体模块更新范围未逐项披露 | 在学生自己生成的前缀上提供 token 级指导，整合专长并保留语言能力 |

**统计边界**：编码器预训练、Audio LLM 预训练和 cooldown 的音频可能重叠，原文没有给出去重关系。不能把“数千万 + 2000 万 + 100 万小时”当成独立音频总量；也没有证据说明每个部署型号独立完整跑过所有阶段。（原文 §3.1–3.6、表1）

## 2. 数据构造：比训练阶段名称更值得迁移的部分

### 2.1 预训练标签和 cooldown 过滤

编码器 AED 数据经过 VAD、多模型伪标注和 ITN；识别器包括 Paraformer-V2、Whisper-large-v3 和 SenseVoice。原文没有给出多识别器投票规则或置信度阈值。

Cooldown 对语言和方言重采样，并用 VibeVoice 重新识别已有 ASR 音频，与原转写比较，去掉 WER > 0.3 的样本。**这是按一致性过滤，原参考文本没有被 VibeVoice 输出替换。** 个人判断：该方法有利于清理错配，但也可能滤掉困难方言、稀有实体或其他识别器不擅长的语音；这项偏差需要按语言、领域和难度检查保留率，论文没有提供相关统计。（§3.1、§3.3）

### 2.2 识别指令与实体增强

- **语言控制**：训练显式指定目标语言；多语种/语码混合按原书写系统保留，避免把低资源语言错误替换为另一种语言。部署时另有方言原样转写与翻译成普通话的任务选择。
- **实体增强**：挖掘 AI、金融、医疗、IT 等领域词表，以检索到的事实为上下文，让 LLM 生成含实体的短句，再用 CosyVoice3 合成。难合成术语补真人录音；由当前 ASR 回识别，过滤实体层面存在明确不匹配的样本。这是实体样本扩充和质量筛选，原文没有把它定义成仅保留当前模型错误的 hard-negative mining。
- **原生润色**：真实音频保持不变，用文本 LLM 重新生成润色标签并做忠实度过滤；合成侧先在规范文本里注入填充词、重复与自我纠正，再 TTS、回识别过滤和加噪。逐字稿与润色稿由二值指令选择，在一次自回归生成里完成。
- **历史上下文**：真实会话根据音频 ID 恢复顺序，只使用此前轮次，不让 LLM 改写历史；合成同音实体配正确、冲突、噪声或空历史。指令明确历史可能错误，当前音频是主要证据。
- **P0/P1 热词**：P0 是高置信高优先级词，P1 是较宽候选集；LLM 依据参考转写做语义匹配并分层。训练同时提供两个列表。论文没有公开 P0/P1 长度、错误候选比例或具体提示词。（§3.4.1）

### 2.3 说话人与通用理解数据

说话人数据混合人工标注与模型监督；影视音频结合原字幕，利用语言识别、声事件检测、说话人模型交叉验证。模拟会议由 LLM 生成话题/对话，并改变混响和噪声。该节没有披露其完整语音合成与混叠实现、重叠比例或说话人数分布。

Next 的理解数据明确覆盖语音、环境声和音乐，包括 caption、带时间区间的 grounding，以及开放/选择式问答。**因此可以说有显式非 ASR 监督；无法据此推断这些能力单靠 ASR 预训练已经形成。** 各任务时长、标签来源、教师质量与混合权重未公开。（§3.4.2–3.4.3）

## 3. SFT 的两个具体优化：监督预算与时间分辨率

### 3.1 输出序列同时监督文字、身份和时间

目标按起始时间排列为多行 `[SPK|start-end]text`；例如 `[SPK0|19.36-23.36]...`。同一录音内同一人保留同一标签，不要求不同时段互斥，因此能表达重叠语音。这是联合自回归生成；SPK 表示录音内身份，不是现实人物识别。（§2.2、§3.4.2）

### 3.2 为什么只给 speaker-ID 数字 token 乘 10

作者先统计未加权监督的构成：

| token 类别 | token 占比 | 未加权 CE 占比 | 最终相对权重 |
|---|---:|---:|---:|
| speaker-ID 数字 | 2.90% | 1.97% | 10 |
| 时间戳 | 33.44% | 49.51% | 1 |
| 格式 | 14.48% | 约 0.23% | 1 |
| 转写正文 | 46.50% | 47.74% | 1 |
| 其他 | 2.68% | 约 0.55% | 1 |

对应的相对加权形式为：

\[
\mathcal L_{\mathrm{SD}}\propto\sum_i w_i\,\mathrm{CE}_i,
\quad w_i=\begin{cases}10,&i\text{ 为 speaker-ID 数字 token},\\1,&\text{其他监督 token}.\end{cases}
\]

\(i\) 遍历被监督的输出 token；原文只指定相对权重，没有给出归一化细节。**加权对象是说话人编号的数字 token，不是整个 `[SPK|start-end]` 片段。** 时间戳已经占近半 CE，无须因为它重要就继续整体加权；格式虽损失小，但作者观察它已能稳定输出，因此也没有加权。

作者称 DER 和 cpWER 明显改善，但没有给出开关重加权的定量消融表。因此可复用的是“先审计 token/损失构成，再针对瓶颈加权”的方法；权重 10 在其他 tokenizer、序列长度和数据分布下仍需验证。（§3.4.2，图5）

### 3.3 时间戳从 1 ms 精度改为 80 ms 网格

编码器与 adapter 输出表示的帧率为 12.5 Hz，即 80 ms/帧。原始标注保留 1 ms 精度，训练时改为与表示对齐的 80 ms 网格；它降低的是**目标标签的时间精度**，不意味着音频采样率降至 12.5 Hz，也不等于真实边界误差保证小于 80 ms。

作者报告在相同数据混合下 loss、DER 和 cpWER 更快收敛且最终更好。图6只有归一化进度上的相对损失曲线，没有绝对 loss、迭代数、收敛倍数和指标差值；具体量化舍入规则也未披露。个人判断：它减少了表示分辨率难以支持的细粒度监督，值得在时间定位任务先做小规模网格消融。（§3.4.2，图6）

## 4. RL：针对困难样本和任务指标，不是通用奖励一把抓

### 4.1 数据选择与 GRPO

ASR RL 数据包括当前模型与 Whisper、FireRed-ASR、SenseVoice 等识别器分歧的困难样本、超过 20 秒的长句、实际幻觉、**真实长重复**、关键词/热词样本，以及用于缓解遗忘的普通 ASR。真实长重复也保留，是为了避免把合理重复一概视为幻觉；原文没有公开该类样本占比。上下文样本保留原历史与指令，避免奖励计算丢掉任务条件。SD 数据则必须带参考转写、说话人和时间边界。（§3.5）

同一输入 \(q\) 采样 \(G\) 条输出 \(o_i\)，得到各自序列奖励 \(R_i\)。原文 GRPO 的组内优势为：

\[
\hat A_{i,t}=\frac{R_i-\mathrm{mean}_{j=1}^{G}R_j}{\mathrm{std}_{j=1}^{G}R_j+\delta}.
\]

\(\delta>0\) 保持数值稳定；同一回答的各 token 使用同一优势。优化再使用当前策略/rollout 策略概率比的 clipped surrogate，以及相对固定参考策略的 KL 惩罚，不单独训练 value 网络。论文没有给出 \(G\)、clip 阈值、KL 系数、采样温度和实际 batch 等值，不能据此直接还原配置。

### 4.2 ASR 与 SD 的奖励组成

| 任务 | 原文披露的奖励 | 训练含义与限制 |
|---|---|---|
| 普通 ASR | \(1-\mathrm{WER}(y^*,y)\)，WER 以比率表示 | 直接对齐序列识别误差；不是所有任务都只优化这一项 |
| 实体 | 关键词准确性与召回 | 同时关注漏识别和插入 |
| 热词 | P0/P1 命中及非对称正负 gamma 权重 | 对带热词样本启用；权重数值未披露 |
| 历史上下文 | 上下文实体命中/漏失和误插入惩罚 | 奖励必须与实际条件一致 |
| 幻觉 | 模式匹配检测，按幻觉片段长度惩罚 | 不是公开训练了一个通用幻觉判别器 |
| 说话人转写 | DER、cpWER、tcpWER 对应奖励 | 分别约束说话活动/混淆、按说话人归属的文字、带时间约束的文字对应 |

\(y^*\) 为参考、\(y\) 为预测。DER 包含漏检、误检与说话人混淆；cpWER 在最优说话人排列下比较逐人拼接的转写，因此不会因编号任意命名而惩罚；tcpWER 再加入时间兼容约束。原文没有给出三项 SD 奖励的最终组合系数、时间容差或完整异常输出处理方式。（§3.5.1–3.5.2）

**范围边界**：论文明确描述的 RL 任务是 ASR 和说话人转写；没有单列音频理解的 RL 奖励。不能把最终 MMAU、MELD 或 grounding 分数都归因为这一阶段。

### 4.3 异步训练基础设施

FunVerl 基于 verl，通过 Ray 编排：音频预处理 → vLLM 多模态 rollout → 按任务/样本来源路由奖励 → Megatron-Core 策略更新；训练支持 tensor、pipeline、expert parallel，通过 NCCL 同步权重。轨迹队列解耦生成、评分和优化，并用 policy-version staleness 阈值排除过旧轨迹。（§3.5，图7）

个人判断：对 MoE 音频模型，采样与训练解耦值得借鉴，但异步版本差、音频预处理一致性、奖励解析和同步开销都应记录。论文没有给出阈值或吞吐/训练成本对照，因此不能声称该框架已被定量证明比某同步实现快多少。

## 5. 多教师在线蒸馏：在学生自己的错误前缀上学习

### 5.1 与固定教师答案 SFT 的区别

OPD 先让当前学生生成 \(\tilde y\)，再让被路由到的教师在**相同输入、相同学生前缀**上给这些 token 打分。教师不是只生成一份固定正确答案供学生模仿；它在学生推理时实际会访问的状态上给指导，包括含学生错误的前缀。（§3.6.1，图8）

原文采用 teacher/student 比率与 \(k_3\) 惩罚：

\[
\rho_t(\theta)=\frac{p_{\phi_k}(\tilde y_t\mid x,\tilde y_{<t})}{\pi_\theta(\tilde y_t\mid x,\tilde y_{<t})},
\qquad d_t=\rho_t-\log\rho_t-1,
\]

\[
\mathcal L_{\mathrm{OPD}}=\mathbb E_{(x,k)\sim\mathcal D,\,\tilde y\sim\pi_{\bar\theta}}
\left[\frac1{|\tilde y|}\sum_t d_t\right].
\]

\(x\) 含任务、音频及可选上下文，\(k\) 为教师身份，\(\phi_k\) 是固定教师参数，\(\theta\) 为被更新的学生参数，\(\bar\theta\) 是 rollout 学生版本。每次学生更新时，教师和已采样轨迹保持固定，再随学生更新采新轨迹。

当 token 真正来自当前学生分布、且教师概率在相关支持集上可用时，\(\mathbb E_{\pi_\theta}[\rho]=1\)，于是该惩罚的期望为 \(D_{\mathrm{KL}}(\pi_\theta\Vert p_{\phi_k})\)。这是**student → teacher 的反向 KL**；不能看见 teacher/student 比率就误写成相反方向。实际异步采样来自 \(\pi_{\bar\theta}\)，所以版本控制是实现条件之一。论文没有详述 rollout 偏差修正、裁剪和梯度实现；估计量的期望恒等式不能替代这些工程细节。

### 5.2 多教师究竟怎样“多”

| 输入任务 | 路由到的教师 | 提供的监督 |
|---|---|---|
| ASR | 专门 ASR 教师 | 转写 token |
| SD | 专门说话人转写教师 | 说话人、时间、文字的联合输出 |
| AU | 专门音频理解教师 | 描述、理解和音频问答 |
| 文本/对话 | Qwen3.5 | 语言、指令和上下文对话 |

每个样本按任务选对应教师；不是让全部教师对每个 token 投票或做概率平均。三位音频教师的确切模型、规模、训练来源，学生规模、各任务比例以及蒸馏超参数均未完整披露。文本/对话回放的设计意图是保留通用语言能力，但报告没有提供“移除文本教师”或“移除某音频教师”的独立消融。（§3.6.2–3.6.3）

**对训练工作的启发（个人判断）**：如果多个专项 checkpoint 分别擅长 ASR、SD 和 AU，可以考虑按任务路由蒸馏到同一学生；应先确认教师在相应任务上确实比学生好、能对学生轨迹返回相容的 token 概率，并评估合并后的任务干扰。论文支持这种训练设计，尚不能证明它在任意模型/预算下优于常规多任务 SFT。

| 通用音频理解从哪里训练出来？ | Cooldown 已加入相关任务，Next SFT 有 caption/grounding/QA，OPD 有 AU 教师 | 无逐阶段或去掉某类监督的对照，无法量化各阶段贡献 |

## 7. 面向自身训练工作的优先实验建议

以下为个人实验建议，并非论文已跑出的结果。应在同一数据切分、音频预算和评分协议下分别观察任务指标，避免仅看总体 loss。

| 优先级 | 实验 | 关键控制与观测 |
|---|---|---|
| 1：低成本 | 统计正文、说话人编号、时间戳和格式的 token 数与 CE 贡献，再比较编号权重 1 与 10 | 只改变目标 token 权重，固定归一化约定；同时看 DER、cpWER、转写误差和格式有效率 |
| 1：低成本 | 原时间标签 vs 与有效帧率对齐的网格 | 先确认自身 encoder+adapter 的有效步长；保持相同时间评分容差，观察收敛、边界误差、DER/tcpWER |
| 2：数据目标 | ASR 基线加入 caption、声学属性、grounding、QA 监督 | 控制训练样本/音频预算，分别报告 ASR 和各 AU 子任务；如关注语气，加入同文本不同语气测试，避免仅靠语义猜情绪 |
| 2：参数策略 | 对比冻结编码器与 SFT 解冻编码器，保持 adapter/LoRA 配置一致 | 固定数据、步数、评测；观察 AU 获益是否伴随 ASR 回退，并记录可训练参数和算力差异 |
| 3：后训练 | 在明确短板样本上加入 RL，与 SFT checkpoint 对照 | 奖励分项可审计；测正常重复被误罚、实体插入、普通 ASR 遗忘和各语言变化 |
| 3：能力合并 | 同一组专项教师下，对比固定答案蒸馏与任务路由 OPD | 控制教师/数据/预算，记录 rollout 版本差与每项任务变化，保留文本/对话评测 |

更直接地说，若当前训练主要是 ASR，却希望保留情绪、说话人或事件时间信息，本文给出的可操作方向是**补充相应监督并检验编码器是否需要更新**；不能仅凭更大的 ASR 数据量或更低的 WER 判断这些能力已经具备。若已有多种专项能力，则 OPD 提供了整合路线，但需要付出教师推理、学生 rollout 和多任务评测的成本。

### 复现前仍需自行确定的配置

- 编码器层数/宽度、adapter 结构、MoE 总/激活参数及声学前端细节。
- 每阶段数据清单、去重关系、语言/任务采样比例、序列时长与截断方式。
- 优化器、学习率及调度、batch、训练步数、LoRA rank/alpha/作用层。
- RL 更新模块、组大小、温度、奖励权重、KL/clip、异常格式处理、staleness 阈值。
- 三位音频教师的身份和质量、tokenization/输出概率兼容方案、OPD 精确梯度与异步修正实现。
- 统一评测脚本、文本归一化、时间容差、重叠语音评分、MMAU split 与提示/抽取规则。

这些是报告中未充分披露的配置，并不表示作者没有使用相应设置。现有内容足够支持训练设计讨论，不足以承诺按表复刻出同一成绩。
