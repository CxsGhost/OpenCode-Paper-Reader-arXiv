已按训练重点阅读 [Qwen-Audio-3.1-ASR Technical Report（arXiv:2610.28711v1）](https://arxiv.org/abs/2610.28711v1)，生成 [训练专题分析](training_analysis.md) 和 [综合阅读报告](summary.md)。以下依据本地 LaTeX 原文 §3，成绩属于作者报告，本次没有独立训练或评测。

最值得关注的训练路线是：先学声学表征，再做大规模音频—语言对齐，随后显式加入新任务监督，最后用 RL 与多教师蒸馏整合能力。

| 阶段 | 数据/监督 | 参数更新方式 |
|---|---|---|
| 编码器预训练 | BEST-RQ → AED；合计数千万小时 | 训练声学编码器；AED 解码器随后丢弃 |
| Audio LLM 预训练 | 约 2000 万小时，主要是 ASR 和交错文本—音频 | 冻结编码器，训练 adapter 与 MoE LLM |
| Cooldown | 约 100 万小时高质量、多任务数据 | 编码器继续冻结，训练 adapter 与 LLM |
| SFT | ASR、说话人转写；Next 加入 caption、时间定位、音频问答 | 更新编码器和 adapter；冻结 LLM 基座，以 LoRA 适配解码器 |
| RL | 困难 ASR、说话人任务；GRPO 优化识别和时间指标 | 原文未逐模块披露冻结范围 |
| 多教师在线蒸馏 | ASR、说话人、音频理解、文本/对话按任务选教师 | 教师固定，学生在自己生成的前缀上学习 |

对训练工作最有参考价值的四点：

1. **非 ASR 能力有显式监督。** Cooldown 已加入相关任务，Next SFT 再用 caption、grounding 和 QA 训练，OPD 有专门 AU 教师。论文没有证明只扩大 ASR 数据就能获得这些能力。（§3.3–3.6）
2. **SFT 重新训练声学编码器。** 预训练和 cooldown 冻结编码器，SFT 则更新编码器/adapter，并用 LoRA 调整语言端；这是一项值得单独做控制实验的策略。（§3.4）
3. **结构化输出需要审计监督分配。** 作者发现说话人编号数字只占 2.90% token、1.97% 未加权 CE，于是只将这类 token 权重乘 10；同时将时间戳从 1 ms 精度量化为与音频表示对齐的 80 ms 网格。其他 token 权重保持 1。（§3.4.2）
4. **RL 与 OPD 提供不同反馈。** RL 用 WER、实体/热词、幻觉及 DER/cpWER/tcpWER 等序列指标；OPD 则让对应教师在学生自己的轨迹上提供 token 级指导，文本/对话教师为 Qwen3.5。（§3.5–3.6）

多教师 OPD 的核心式为 \(\rho_t=p_{\mathrm{teacher}}/p_{\mathrm{student}}\)、\(d_t=\rho_t-\log\rho_t-1\)。在当前学生 on-policy 采样条件下，其期望估计学生到教师的反向 KL。每个样本按任务选择对应教师，不是把全部教师的概率简单平均；异步版本差和梯度实现等细节仍需自行核实。（§3.6）

实验上，GigaSpeechBench 所列七语言宏平均错误率从 3.0 的 22.50% 降至 15.09%；但 AISHELL-1 CER 从 1.03% 到 1.08%，FLEURS-en WER 从 4.17% 到 4.72%。这说明最终能力有增有减，不能仅凭历史版本对比定位是哪一步训练造成变化。（§5.1，表2–3）

论文未公开完整任务配比、模型参数规模、LoRA rank、学习率和步数、奖励系数与逐阶段消融；说话人重加权和时间量化的收益也没有完整定量消融表。因此，它适合借鉴训练设计，尚不足以直接照配置复现。建议优先做监督 token 占比/损失审计、时间网格消融，再评估加入 AU 数据和解冻编码器的收益与回退。训练专题已整理这些可验证项及原文定位。
