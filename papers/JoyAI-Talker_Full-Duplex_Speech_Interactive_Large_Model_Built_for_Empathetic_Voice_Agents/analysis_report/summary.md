# JoyAI-Talker: Full-Duplex Speech Interactive Large Model Built for Empathetic Voice Agents

> arXiv: 2608.01119 | 2026-08-02
> 作者: Yinhao Bai, Jinming Chen, Yafeng Chen, Wei Deng, Boya Dong, Nan Duan 等 (JD.com)

---

## 背景与动机

大语言模型 (LLM) 的快速发展推动了智能对话代理的进步，但语音作为人类最自然、最具表达力的沟通方式，研究范式正从纯文本模型向大型语音语言模型 (LSLM) 转变。传统的级联式语音对话系统 (ASR → LLM → TTS) 存在延迟累积和副语言信息丢失的问题。尽管 GPT-4o、Gemini 3.1 Live 等端到端模型取得了突破，但实现真正类人的沉浸式对话仍面临三大根本挑战：

1. **模态引起的认知退化**：将连续高维语音整合到 LLM 的离散语言空间中，往往导致"灾难性遗忘"，模型在逻辑推理、数学等方面的能力显著下降
2. **缺乏动态共情能力**：现有语音助手生成平淡的通用回复，无法动态感知说话人的年龄、性别、情绪等属性并做出个性化共情回应
3. **脆弱的全双工交互**：传统全双工系统存在高误触发率，要么过度反应（对背景噪声敏感），要么过度保守（无法在用户打断时让出话轮）

## 问题定义

如何构建一个全双工语音对话系统，使其同时满足：
- 保持强大的文本推理和认知能力（不因语音融合而退化）
- 实现动态、个性化的共情交互
- 稳定、鲁棒的实时轮次控制（高响应率 + 低误触发率）

## 核心创新

### 1. Duplex-Thinker-Talker 解耦架构
- 将对话状态协调、认知语义推理、表达性语音合成分离为独立模块
- 避免将高频、低层的流式分类任务整合到主干语言模型中，从而保护认知核心

### 2. 统一语音-文本联合训练
- 从中训练（Mid-training）阶段就开始语音-文本联合训练（而非延迟到 SFT 阶段）
- 贯穿 Mid-training → Context Extension → SFT → DPO 四个阶段
- 有效缓解认知退化，MATH 基准达到 94.62%

### 3. PAER（Persona-Adaptive Empathetic Response）框架
- 层级认知管线：音频理解 → CoT 推理 → 共情对话生成
- 从原始音频中提取说话人属性（性别、年龄、情绪状态）
- 将感知结果融入 Thinker 的 CoT 推理，生成上下文自适应的回复

### 4. 文本可控的表达性语音生成（Talker）
- 基于 JoyVoice 架构：自回归 Transformer + 因果扩散 Transformer
- 支持自然语言指令控制声音属性（情绪、语速、音量等）
- 10 种副语言特殊 token（[Laughter], [Sigh], [Cough] 等）实现局部非语言事件控制
- 通过语音转换实现低成本目标音色适配（Style Borrowing）

### 5. Joy-Duplex 全双工框架
- 状态驱动的即插即用设计，不修改主干模型参数
- 轻量级 1.7B 解码器，交错预测文本 token 和状态 token
- 5 种交互状态词汇：`<|partial|>`, `<|complete|>`, `<|backchannel|>`, `<|accept|>`, `<|reject|>`
- 基于语义的门控决策，而非传统的帧级能量检测

## 方法论

### 整体架构

```
[用户语音] → Audio Encoder → Hybrid MoE Thinker (48.9B, 3.28B active)
                                    ↓
                          文本回复 + TTS 指令 token
                                    ↓
                    Causal AR Transformer → Dynamic Chunk DiT → Vocoder → [语音输出]
```

### Thinker 模块
- **语音编码器**：基于注意力的编码器-解码器架构，8× 下采样，12.5Hz token 率
- **语言主干**：JoyAI-LLM Flash，48.9B 参数 MoE 模型（每 token 激活 3.28B）
  - 40 层 Transformer（1 层 Dense + 39 层 MoE）
  - 每层 256 个细粒度专家，Top-8 路由 + 共享专家
  - MLA + RMSNorm + RoPE + SwiGLU

### 四阶段联合训练
| 阶段 | 序列长度 | 关键内容 |
|------|----------|----------|
| Mid-training | 8K | Step 1: 冻结 LLM+Encoder，只训练 Adapter；Step 2: 全参数联合优化 |
| Context Extension | 64K | 上采样长上下文数学/代码数据 + 长语音对话 |
| SFT | 64K | 文本 SFT + 语音 SFT，上采样 S2T 合成数据 |
| DPO | - | 三种 Judge（通用 QA / IF / 规则）打分，语音-only 策略构建偏好对 |

### Talker 模块
- **层级指令**：全局指令（角色、性别、音色）+ 局部指令（当前话语的情绪、语速、音量）
- **序列公式**：$\mathcal{I} = [P_{sys}; I^g; spk; I^l; t_1...t_N; s_1...s_M]$
- **流式生成**：支持流式文本输入 + 流式语音输出
- **Style Borrowing**：通过语音转换将电影/电视中丰富的表演风格迁移到目标助手音色

### Joy-Duplex 模块
- **流式音频编码器**：160ms 非重叠分块，动态分块注意力策略
- **交错序列建模**：每帧输出 Text Tokens → `<|asr_eos|>` → State Token
- **语义门控**：只有当解码器输出 `<|accept|>` 时才触发下游 SDM 生成回复
- 可选的说话人验证 (SV) 插件并行运行

## 实验结果

### T2T 评估（14 个基准）
| 类别 | 主要结果 |
|------|----------|
| 知识 | MMLU-Redux 90.80%, C-Eval 87.97% |
| 推理 | MMLU-Pro 80.23%, SuperGPQA 54.31% |
| STEM | **MATH 94.62%**, MATH-500 94.58%, GPQA 64.51% |
| 指令遵循 | IFEval 83.70% |
| 长上下文 | RULER(64K) 76.88% |

所有指标均优于 Qwen3-Omni (32B/3B active)，证明联合训练有效保持了文本能力。

### S2T 评估（23 个基准）
- ASR: Aishell-1 WER 0.86%, LibriSpeech-clean 1.32%
- 翻译: CoVoST-2 en→zh 51.29 BLEU
- 语音 QA: OpenBookQA 94.73%, MMSU 84.65%
- EQ 感知: 性别 98.25%, 年龄 77.30%, 情绪 79.57%

### 共情对话评估（EchoMind）
| 子集 | 加权总分 | 共情评分 |
|------|----------|----------|
| Emotion | 9.38 (vs Qwen3-Omni 8.91) | 8.28 (vs 7.71) |
| Age | 9.08 (vs 8.91) | 7.49 (vs 7.03) |
| Gender | 9.79 (vs 9.47) | 9.73 (vs 9.20) |

### 全双工评估（Full-Duplex-Bench v1.5）
| 场景 | Joy-Duplex | GPT-4o | Gemini 3.1 Live |
|------|------------|--------|-----------------|
| 用户打断 (Respond↑) | **0.88** | 0.78 | 0.77 |
| 用户反馈 (Resume↑) | **0.96** | 0.70 | 0.95 |
| 对他人说话 (Respond↓) | **0.17** | 0.91 | 0.27 |
| 背景语音 (Respond↓) | **0.10** | 0.93 | 0.28 |

Joy-Duplex 在所有四个场景均达到 SOTA，展现出高响应性与低误触发的最佳平衡。

### 语音工具调用
- Speech-ACEBench (Single): 98.56% (优于 Qwen3-Omni 92.79%)
- 证明文本域 Agent 能力成功迁移到语音交互

## 结论与展望

JoyAI-Talker 通过解耦的 Duplex-Thinker-Talker 架构，成功解决了语音对话系统中认知退化、缺乏共情和全双工不稳定三大难题。系统在保持强大文本推理能力的同时，实现了表达性强、共情能力出色、全双工稳定的语音交互。

**未来方向**：
1. 扩展通用音频事件推理能力（环境声、警报等）
2. 完成大规模 RL 训练以提升复杂指令遵循和语音 Agent 调用
3. 探索端到端双流架构与模块化状态驱动方案的对比优化

## 个人评价

**优势**：
- 架构设计精巧：三模块解耦既保证了各组件独立优化的灵活性，又避免了端到端训练对认知能力的损害
- 联合训练策略完善：从 mid-training 就开始语音-文本联合训练是一个重要的工程洞察，DPO 阶段的"语音-only"偏好对策略也很巧妙
- PAER 共情框架有理论深度：层级认知管线模拟人类认知过程，是技术与认知科学的有机结合
- 全双工方案实用性强：1.7B 轻量解码器 + 5 种状态 token 的设计简洁高效，即插即用的特性便于工程部署
- 实验全面：T2T/S2T/共情/全双工/工具调用五个维度的评估充分验证了系统能力

**不足**：
- Parallel Tool Calling 性能较弱（Speech-ACEBench Parallel 仅 44.32%），复杂 Agent 场景仍有提升空间
- CoT 模式下部分感知能力有所下降（如性别识别从 98.2% 降至 89.3%），端到端推理链可能引入噪声
- 未开源模型权重和代码，可复现性受限
- 延迟指标未明确报告（仅定性提及"略高于单通道模型"）
- 缺乏与 GPT-4o 在语音生成质量（MOS 等）方面的直接对比
