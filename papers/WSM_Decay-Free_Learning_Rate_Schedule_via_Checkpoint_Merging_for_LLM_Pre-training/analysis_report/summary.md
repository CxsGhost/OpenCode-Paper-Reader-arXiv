- **依据**：已阅读 `main.tex` 引入的全部章节及附录，以 LaTeX 源码为主，关键图为补充。以下实验值均为**作者报告值**，未独立复现实验。

## 1. 背景与问题定义

传统 warmup + cosine decay 需要预先确定训练终点；WSD（Warmup-Stable-Decay）通过恒定学习率平台期提高灵活性，但仍需安排衰减起点、时长与曲线。如果还要继续加入数据，已有衰减分支的调度需要重新考虑。

WSM（Warmup-Stable and Merge）研究的问题是：**能否让训练主线一直保持恒定学习率，用同一训练轨迹上近期 checkpoint 的参数合并，获得类似退火、甚至更好的评测模型？**它合并的是同一模型训练过程中的参数快照，不涉及多模型推理集成，也不要求多次独立训练。

来源：原文 §1–2；[intro.tex](../src/sections/intro.tex)、[pre.tex](../src/sections/pre.tex)。

## 2. 核心创新

1. **统一合并与衰减的数学表示**：将 checkpoint 加权平均改写为历史参数更新的重加权，并给出从目标单调衰减系数反推合并权重的公式。
2. **解耦训练与模型交付**：恒定学习率主线持续训练；异步或离线合并产生评测/交付模型。同一条轨迹可事后探索不同窗口和权重，无需为每种退火方案重新训练。
3. **实证分析合并窗口**：作者发现，覆盖多少训练 token 通常比单独增加 checkpoint 数量更重要；在其 Ling-mini MoE 实验中，WSM 优于 WSD，收益还能部分保留至后续 SFT。

权重平均已有较长研究历史，本文的贡献主要是上述统一视角、训练流程及大规模 MoE 实证。合并窗口和权重仍需选择，不能将“去掉在线学习率衰减”理解成“没有超参数”。

来源：原文 §1、§3、§5；[method.tex](../src/sections/method.tex)、[rela.tex](../src/sections/rela.tex)。

## 3. 方法与关键公式

### 3.1 为什么合并能产生“衰减式”的更新权重？

设同一训练轨迹的 checkpoint 为 $\theta_n,\ldots,\theta_{n+k}$，$g_i$ 表示已发生的参数更新向量，**包含学习率**，满足 $\theta_{i+1}=\theta_i-g_i$。用非负且和为 1 的权重 $c_j$ 合并：

$$
\hat\theta_{n+k}=\sum_{j=0}^{k}c_j\theta_{n+j}
=\theta_n-\sum_{i=1}^{k}w_i g_{n+i-1},\qquad
w_i=\sum_{j=i}^{k}c_j.
$$

早期更新被更多后续 checkpoint 共享，晚期更新出现的次数更少，因此非负合并权重自然对应单调不增的历史更新系数。例如，平均四个连续 checkpoint 时，三个区间更新的系数依次是 $3/4,1/2,1/4$，呈离散线性下降。

反过来，给定 $1\ge w_1\ge\cdots\ge w_k\ge0$，定理 3.1 给出唯一的归一化非负合并权重：

$$
c_0=1-w_1,\qquad c_j=w_j-w_{j+1}\;(1\le j<k),\qquad c_k=w_k.
$$

由此可构造近似线性、cosine 或论文所称 **1-sqrt** 曲线的合并方案。图 2 直接标出的 1-sqrt 是 $w(t)=1-\sqrt{t}$（$t$ 为归一化进度），不要仅根据摘要中的“inverse square root”将其写成 $1/\sqrt{t}$。该图中的 1-sqrt 合并更重视窗口早期 checkpoint，EMA 更重视近期 checkpoint。checkpoint 稀疏时，对区间内更新施加的是分段常数权重。

**适用边界**：对一条已经发生的参数轨迹，上述重排是代数恒等式；但重新运行真正的衰减训练会改变参数位置、后续梯度及 AdamW 状态，因此通常不会得到相同轨迹或终点。原文为简化分析明确假定更新独立并忽略优化器状态。其“兼容不同优化器”是框架层面的性质，主实验使用 AdamW，不能扩展成对所有优化器和任务的性能保证。

来源：§3.1，式 (1)–(5)、定理 3.1；[method.tex](../src/sections/method.tex) 第 8–62 行；附录 B [appendix.tex](../src/sections/appendix.tex) 第 48–133 行。

曲线核对：[原图 2](../src/figs/decay_style_comparison.pdf)。

### 3.2 实际训练流程

1. 线性 warmup 至 $\eta_{\mathrm{peak}}$，此后主线始终保持该学习率。
2. 可在 $T_{\mathrm{switch}}$ 切换到高质量数据；WSM 去掉的是学习率衰减，不排斥数据配比切换。
3. 每隔一定训练 token 保存**未合并的主线 checkpoint**。
4. 异步或离线取最近 $n$ 个 checkpoint，以均值或定理生成的权重合并，供评测/交付。

算法 1 中，合并结果不写回训练主线，主线按原有优化器状态继续。离线方案适合探索窗口；固定方案可用滑动窗口实现在线合并，代价主要是 checkpoint 存储与读写。作者指出 $n=12$ 这样的较小窗口已能取得较好结果，但没有给出可迁移到所有训练规模的固定最优值。

来源：§3.2–3.3、算法 1；[method.tex](../src/sections/method.tex) 第 65–136 行。

### 5.2 消融与机制证据

- **合并算法**：Overall Average 为 WSD 62.67、EMA 63.01、Mean 63.95、1-sqrt 64.06。Mean 与 1-sqrt 优于该实验中的 EMA，1-sqrt 仅略胜 Mean，不能据此断言 EMA 普遍无效。
- **窗口时长**：均值和 1-sqrt 合并通常随覆盖窗口增大而改善，但收益递减。作者将时长视为最关键因素；这属于所测设置的经验发现。
- **固定时长再看粒度**：名义 80B 窗口下，(5B,16)、(10B,8)、(20B,4)、(40B,2)、(80B,1) 的综合分依次为 63.63、63.78、63.36、62.77、60.33。多个 checkpoint 明显优于单点，但“越密越好”并非严格单调。表 4 的 Language Modeling 列出现约 80 分，与主表及部分行的综合分关系可疑，保留原值而不自行修正。
- **训练中途评估**：在 2T/4T/6T/8T/10T 附近，合并最近名义 100B 窗口的 4 个 checkpoint，表现接近另行训练的 100B 衰减分支，可用于观察退火后潜力。
- **合并与衰减叠加**：先衰减再合并、先合并再衰减，在所测实验中均未出现额外最终收益，支持二者具有部分替代关系。
- **MoE 路由**：WSM 的 max/min load violation 从 0.601/0.322 降至 0.545/0.201，但语言建模 loss 从 0.675 升至 0.697。下游收益不等于训练 loss 更低；这些指标及附录中的条件数、SVD 熵、t-SNE 仅提供机制线索，不能证明泛化或持续学习能力的因果改善。

注意窗口约定：论文用 $n\times$ 保存间隔描述名义覆盖量，例如 4 个 checkpoint ×25B=100B；若只计算首末 checkpoint 的时间戳差，实际是 $(n-1)\times25B$。复现时应记录具体端点。

## 6. 结论与展望

作者的结论是：恒定学习率训练加 checkpoint 合并，可以在其大规模 MoE 预训练实验中替代 WSD 的退火分支，并提高所测综合能力，部分收益保留至 SFT。未来计划探索更多合并权重，以及把框架用于数据混合比例优化。

这项工作更有说服力的证据是训练流程的可行性、窗口/权重消融与下游评测；它没有证明任意模型、优化器或数据分布下都能替代真实衰减，也没有提供完整持续学习任务上的遗忘与适应实验。

来源：§6 [conclu.tex](../src/sections/conclu.tex)。

## 7. 个人评价与训练实践启示

**我的判断**：WSM 的工程价值在于，让持续训练主线与可交付模型的退火效果分开管理。已经保存了同一轨迹近期 checkpoint 时，离线平均的试验成本较低，可先检查它能否减少高学习率末期波动，而不必立即安排额外退火训练。图 3 中 400B 位置的 WSM 曲线也高于 WSD，说明优势趋势并非只在延长训练后出现，但严格的数值比较仍需固定 token 预算。

迁移到自己的实验时，可先比较相同终点、相同数据、相同评测设置下的“原始 checkpoint / 均值合并 / WSD”，优先改变**窗口覆盖 token 数**，再固定时长改变 checkpoint 间隔；保留每个候选的端点与选模依据。这是基于论文的实验设计建议，不是作者已经验证的通用最优配方。

尤其注意：**Decay-Free 仅指学习率不衰减，AdamW 的 weight decay 仍是 0.1。**常规训练继续使用主线权重与优化器状态；若另从合并权重启动训练，需要单独处理状态衔接，本文并未给出普遍适用的保证。

主要限制是实验集中于一种 MoE 架构，缺少多规模/多种子验证；高质量数据与 SFT 配方不完整；峰值学习率、摘要增益口径及部分表格条目存在不一致。原文还将 1-sqrt 称为“inverse square root”，并在文字中混用曲线凹凸描述，具体实现应以图中公式和实际权重为准。因此可借鉴方法和对照设计，不能直接把报告分数或超参数当成可复现承诺。
